## Important
The five agents are OMS, IMS, TMS, Verification and Finance/Compliance. The owner confirmed this roster. Shared policy, identity, transition/reservation/finance execution, notifications, audit and human review are controls, not a sixth autonomous AI agent.

This is review-ready specification, not production-ready software. No repository or live workspace changes were made to create this package. No application/runtime tests were run. No publication, migration, real-money execution, live M7 or Qwen activation is authorized by these files. Open policies remain null/disabled, never inferred from examples. Existing PostgreSQL test gaps do not disappear because Xano is the target.
